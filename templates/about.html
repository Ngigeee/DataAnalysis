About Kijarney

Kijarney is a visual data science platform that enables anyone to analyse data without writing code.

Features

  • Upload CSV and Excel datasets
  • Clean datasets visually
  • Remove duplicates
  • Handle missing values
  • Visualize data instantly
  • Machine learning tools
  • Dataset management
  • Export cleaned datasets

Mission

To make professional data science accessible to everyone through an intuitive graphical interface.
